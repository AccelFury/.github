For evaluation, licensing or engineering, describe the function, interfaces, target and acceptance criteria. Include a component name if known; timelines and support needs are optional.

Start with a non-confidential summary. Agree on an NDA and a transfer channel before sharing design files.

For technical support, include the component version, tool versions, expected and observed behavior, and the command used. Remove credentials and confidential data from any diagnostic material.

For security reports, use the subject `[AccelFury Security] <repository> / <summary>` and contact us before publishing sensitive details.
